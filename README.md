# qa_python

1. тест test_set_book_genre проверяет установку жанра книге на примере Гордость и предубеждение и зомби
2. тест test_get_book_genre проверяет получение жанра книги по ее имени 
3. тест test_get_books_with_specific_genre проверяет вывод списка книг с определенным жанром, позитивный и негетивный сценарий (наличие книг и их отсутствие)
4. тест test_get_books_genre проверяет получение словаря books_genre
5. тест test_get_books_for_children проверяет подходят ли книги детям по названию
6. тест test_add_book_in_favorites проверяет добавление книги в избранное
7. тест test_delete_book_from_favorites проверяет удаление книги из избранного
8. тест test_get_list_of_favorites_books проверяет получение списка избранных книг
